# PianoReader
### by Kerem Ceylan
<br>

---
**IMPORTANT!**

This program is meant for **midi pianos** more specifically
my own RD-88 stage piano! Any other type of midi device 
is not ideal and not meant for this program. I highly
recommend testing your midi device in a DAW first (preferably 
[CakeWalk](https://www.cakewalk.com/sonar) or FL Studio)
if not done already. Configurations can be made in PianoReader.java
---

## What my program does

Simply put, it shows what Note or chord you are
currently playing. It can also try to guess what song
you might be playing using AI song detection.
